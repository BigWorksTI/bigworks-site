# BigWorks Site

Site institucional da BigWorks — estilo vCard editorial, compatível com Vercel.

**Produção:** https://site.bigworks.com.br

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- Node 24

## Desenvolvimento

```bash
npm install
npm run dev
```

## Deploy (Vercel)

1. Importar repositório `BigWorksTI/bigworks-site`
2. Node.js **24.x**
3. Domínio: `site.bigworks.com.br`

Build: `npm run build` · Output: Next.js default
